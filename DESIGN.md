# Design
A bright drawing review desk for use in an illuminated construction office. White drawing canvas, warm paper surroundings, ink typography and restrained dark green measurement marks. DM Sans for interface text; tabular numerals for measurements. The drawing and highlighted boundary carry the visual identity. No decorative imagery.
The operating workspace puts the drawing beside the question, result, source checks and room list. The first action loads a real licensed DXF example. Mobile stacks the drawing before the proof. Controls remain labelled and keyboard usable.
